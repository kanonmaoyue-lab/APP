# 小日子重建实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 按用户已确认的功能重建 iPad 日历 PWA，并把开发环境配置与保存状态分开验证。
**Architecture:** React 视图与纯日期／复习／路线算法分离；Dexie 保存账号基线、顺序离线队列和冲突；Supabase RPC 在账号锁内做幂等版本检查、原子写入／评分与完整批次增量同步。ORS 经认证 Edge 代理，缺配置时明确报错。
**Tech Stack:** TypeScript、React、Vite、Temporal、Dexie、dnd-kit、Supabase、Vitest、Playwright、Deno。
**Spec:** docs/superpowers/specs/2026-10-17-calendar.md（复述先前批准方案，不是新设计）

## Global Constraints
- 使用当前隔离检出，不创建 worktree；不擅自推送、发布或创建第三方项目。
- iPad 横竖屏与 44px 操作区；静态缓存，不缓存账号和地图 API。
- 复习间隔 `[1,3,7,14,30]`，每天最多一次评分，按实际评分日计算。
- 最多 8 个目的地，交通方式跟随目的地，固定预约不移动，预览和明确采用分开。
- 不静默覆盖冲突，不复活已删记录；账号切换不泄漏旧账号 UI。
- 未验证真实校区路线、托管云端与 iPad 时，不宣称完成这些验收。

## Review Focus
- 离线连续修改、丢失确认与多标签页锁接管：任务2／3测试幂等重试、版本重基与租约释放。
- DST 缺口／重叠和跨午夜：任务1测试解析策略与半开区间；任务4检查显示与移动。
